# ml/

Python code for datasets, training, evaluation and inference. **Empty until Milestone 3.**
Python will be managed with `uv` and pinned versions in `pyproject.toml` / `uv.lock` (ADR 0001).

- `data/` dataset capture manifests and split definitions (raw images stay out of Git)
- `training/` model training scripts
- `evaluation/` metrics and confusion-matrix tools
- `inference/` model export and inference wrappers
